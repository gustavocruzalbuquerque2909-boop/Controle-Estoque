# 📦 Controle de Estoque Pro

Sistema de gerenciamento de estoque moderno com interface responsiva em **Dark Mode** e integração com API REST em C# .NET.

## 🚀 Funcionalidades
- **Tela Inicial de Boas-Vindas**: Navegação intuitiva antes do painel principal.
- **Gerenciamento de Produtos**: Cadastro, listagem, edição e exclusão (CRUD).
- **Relacionamentos**: Associação de produtos a Categorias e Fornecedores cadastrados.
- **Interface Dark Mode**: Design escuro, limpo e focado na usabilidade.

## 🛠️ Tecnologias Utilizadas
- **Front-End**: HTML5, CSS3 (Custom Dark Theme) e JavaScript Assíncrono (Fetch API).
- **Back-End**: C# / ASP.NET Core Web API.
- **Banco de Dados**: SQL Server.

## 💻 Como Executar o Projeto

1. Execute a API Back-End em C# (Servidor ativo em `http://localhost:5196`).
2. Abra o arquivo `tela.html` com a extensão **Live Server** no VS Code.
3. Clique em **Acessar Sistema** para navegar até o painel.
